# dotfiles

## CLI Commands

A lot of these are classic unix CLI commands rewritten in Rust with enhanced features and blazing speed.

|Tool|Explanation|
|---|---|
|bat|cat alternative|
|delta|diff alternative|
|eza|ls alternative|
|fd|find alternative|
|fzf|Fuzzy finder search (goated)|
|rg|grep alternative|
|zoxide|cd on steroids|

## Cool Software

|Tool|Explanation|
|---|---|
|ghostty|Terminal emulator|
|lunarvim|Text editor|
|starship|Shell prompt|
|tmux|Terminal splitter that allows background usage and reconnecting|

## Package Management

|Tool|Explanation|
